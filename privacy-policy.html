Privacy Policy

Last updated: August 2026

This privacy policy describes how the "Relaxing History" application ("the App") accesses and uses Google user data via the Google APIs and YouTube API Services.

What the App Does

The App is private software used by its developer to manage and publish content to one specific YouTube channel. It is not a public-facing service, and it is not made available for use by any third party or any other Google account.

What Data the App Accesses

The App requests the following Google API scopes, solely to upload videos and thumbnails to the developer's own YouTube channel:

  • https://www.googleapis.com/auth/youtube.upload - to upload video files and associated metadata (title, description, tags) to the channel.
  • https://www.googleapis.com/auth/youtube - to set a custom thumbnail image on uploaded videos.

The App also uses a separate Google service account (not tied to any individual Google user's consent) to read and write a private Google Sheet used internally for production scheduling, and to read two static asset files (a logo image and an audio file) from a private Google Drive folder. No data from these sources is shared with any third party.

What the App Does Not Do

  • The App does not collect, store, or share any personal data belonging to viewers of the uploaded videos.
  • The App does not access, read, or use any Google user data belonging to any account other than the developer's own.
  • The App does not sell, rent, or transfer any accessed data to any third party.
  • The App does not use accessed data for advertising purposes.

Data Retention

Access tokens and refresh tokens are stored only within the developer's own private, self-hosted automation server and are not transmitted to or stored by any third party. Tokens can be revoked at any time via the developer's Google Account permissions page.

Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be directed to the developer via the contact details provided in the associated Google Cloud project's OAuth consent screen configuration.
